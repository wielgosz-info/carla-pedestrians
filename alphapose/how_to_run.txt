Other commands to remove exiting containers

# 1. Stop and remove current container
docker-compose -f "docker-compose.alphapose.yml" down

# 2. Remove old image
docker rmi pedsynth-alphapose:latest

# 3. Rebuild image
docker build -t pedsynth-alphapose:latest -f Dockerfile.alphapose .

# 4. Start container again
docker-compose -f "docker-compose.alphapose.yml" --env-file .env up -d
